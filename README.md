# vitrina-ai

A lightweight, responsive single-page prototype of an **AI blogger showcase** (Landing Page) with a mobile-first focus. Built as a test assignment to demonstrate skills in working with generative AI tools and a modern frontend stack.

## About the Project

The goal was to create a sleek, stylish, and interactive landing page presenting a catalog of 4 virtual AI bloggers:

- 👨 **Male Blogger #1** — Sports / Fitness
- 👨 **Male Blogger #2** — Business / Tech
- 👩 **Female Blogger #1** — Fashion / Lifestyle
- 👩 **Female Blogger #2** — Creative / Art (45 y.o.)

Each character has a unique look, style, and blog theme. The design uses a **black and red color scheme** with white text.

## Tech Stack

- **Next.js** — React framework for production-grade apps
- **React** — UI library
- **Tailwind CSS** — utility-first CSS framework
- **TypeScript** — type safety
- **AI image generation** — creating realistic blogger portraits without artifacts

## Features

- ✅ Responsive layout with mobile-first priority
- ✅ Modern premium UI/UX with subtle animations
- ✅ Blogger cards with portrait, name, description, and a "View Blog" CTA button
- ✅ Interactivity: clicking a blogger opens a modal with a mini content feed
- ✅ Prominent "Go to Telegram" CTA button
- ✅ Glassmorphism effects, smooth transitions, 44px+ touch targets

## AI Art

All 4 characters were generated using generative neural networks. Each one has a carefully crafted visual identity:

| Blogger | Niche | Style |
|---------|-------|-------|
| Male #1 | Sports / Fitness | Athletic wear, dramatic lighting, red rim light |
| Male #2 | Business / Tech | Business suit, cool lighting, red accents |
| Female #1 | Fashion / Lifestyle | Designer outfit, warm lighting, red highlights |
| Female #2 | Creative / Art | Elegant look, soft lighting, red rim light |
